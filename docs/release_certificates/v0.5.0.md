## Speed — against the previous release

The release figures are the quiet pass of 2026-10-28 on `4731e5a`, the median of three with
FiniexTestingIDE's container at 9–10 % CPU. What came after it changes no measured list: the Layers
panel's rows, the chart's header, and a hidden sign that the chart places and does not paint. On the release tree the spec ran again while FiniexTestingIDE
ran its full test suite at 260–340 % CPU: every figure rose by 10–50 %, as that load does, and none
doubled.

| Measure | v0.4.0 (2026-10-16) | v0.5.0 (2026-10-28, quiet) | release tree, under load |
|---|---|---|---|
| run list — cold, app only | 378 ms | 436 ms (436 / 500 / 396) | 527 ms |
| run list — warm | 304 ms | 318 ms (318 / 319 / 296) | 392 ms |
| run chosen → panels usable | 341 ms | 343 ms (350 / 343 / 341) | 433 ms |
| narrowing across panels | 117 ms | 129 ms (129 / 110 / 129) | 170 ms |
| trade history drawn | 33 ms | 24 ms (27 / 24 / 22) | 43 ms |
| run chart — a unit drawn | not measured then | 144 ms (166 / 144 / 136) | 215 ms |
| run chart — a zoom step | not measured then | 85 ms (85 / 90 / 85) | 100 ms |
| sweep — 500 combinations | not measured then | 596 ms (615 / 596 / 589) | 739 ms |
| deployment → bundle drawn | new in this release | 154 ms (152 / 166 / 154) | 198 ms |
| frames — a step drawn | new in this release | 91 ms (93 / 91 / 91) | 99 ms |

The run chart's figures and the sweep's were added between the releases (2026-10-19 and 2026-10-20);
the deployment bundle and the frame player had no measuring point until this release added one each,
before measuring.
