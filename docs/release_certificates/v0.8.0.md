## Known and accepted

- **v0.7.0 was measured under load and this release quiet**, so a figure that reads lower here is not proof of a gain.
- **The pass before this release, on 2026-11-19 under heavy load, read a session's series at 3030 ms.** Under the same load, the code before the cycle read it at 3182 ms; quiet, it reads 901 ms. It was the load, not the code.
- **The ⓘ in a short header:** below 28rem, the ⓘ beside the run chart's quick bar gives way, as the link button does, so the unit's name keeps its room. The run chart's help then waits for a wider header.
- **Layers without options** (the state frame, the booking periods, the refused and the resting orders) explain themselves in the help card on their name. Their whole text has no ⓘ, as before the cycle.
- **`ts_event`** (contract 58) is mirrored and not drawn: none of the captured runs carries one.
- **This version mirrors contract 58.** Against another contract, the status bar says that the two contracts differ.
- **The README's pictures** show runs from FiniexTestingIDE's fixture catalogue, taken against the live API.
