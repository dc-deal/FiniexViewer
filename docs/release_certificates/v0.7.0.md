## Speed — against the previous release

No quiet pass was possible on the release tree. FiniexTestingIDE's container ran at 48–54 % CPU
throughout, and this repository's dev server at 49–54 %. v0.6.0 was measured under load as well
(the IDE at 19–298 %), so the two columns compare like with like. A doubling is the threshold.
Every figure stays well below it, and most read lower than in v0.6.0.

| Measure | v0.6.0 (2026-11-05, under load) | v0.7.0 (2026-11-12, under load) |
|---|---|---|
| run list — cold, app only | 551 ms | 515 ms (591 / 515 / 502) |
| run list — warm | 401 ms | 369 ms (404 / 369 / 369) |
| run chosen → panels usable | 395 ms | 428 ms (405 / 490 / 428) |
| narrowing across panels | 167 ms | 160 ms (160 / 160 / 156) |
| trade history drawn | 36 ms | 39 ms (45 / 24 / 39) |
| run chart — a unit drawn | 176 ms | 155 ms (190 / 152 / 155) |
| run chart — a zoom step | 103 ms | 88 ms (93 / 88 / 85) |
| run chart — a zoom step over the time lane | new in this cycle | 90 ms (93 / 90 / 83) |
| run chart — the legends at a pointer move | new in this release | 116 ms (121 / 116 / 111) |
| run chart — a gap crossed | 302 ms | 265 ms (295 / 265 / 259) |
| sweep — 500 combinations | 806 ms | 782 ms (782 / 810 / 700) |
| deployment → bundle drawn | 218 ms | 205 ms (224 / 187 / 205) |
| frames — a step drawn | 105 ms | 96 ms (97 / 96 / 94) |
| frames — a step, the chart beside | 110 ms | 104 ms (105 / 100 / 104) |

A unit drawn now includes the volume in its own pane, and still reads below v0.6.0. A legend
update at a pointer move takes two browser round trips, as a zoom step does. Its own share is
therefore at most the difference between the two figures.

## Known and accepted

- The speed was measured under FiniexTestingIDE's load, as in v0.6.0. Against v0.6.0, two figures read 8 % higher: panels usable at 428 against 395 ms, with its middle run at 490 ms, and the venue account at 103 against 95 ms. Both are inside the noise of a busy machine and should be read again at the next quiet pass.
- The speed pass and the three browser runs came before the mirror of contract 54. That mirror changed one line of the scenario card and the fixtures' stamps. A fourth browser run on the release tree covers it.
- A run recorded before contract 54 keeps the drawdown start it was written with, which is on the wall clock. The scenario card shows that instant with no clock named, because the response does not say which clock a value is on.
- The cold figure includes the test browser's own stall before any code of the app runs. The app-only figure is read on the page's own clock.
- This version mirrors contract 54. Against an older contract, the status bar says that the two contracts differ.
- The run chart no longer shows the chart library's logo. Its licence is met by the `NOTICE` file and by the library's line in the About dialog.
- The README's pictures show runs from FiniexTestingIDE's local archive, taken against the live API.
