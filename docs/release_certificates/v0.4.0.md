## Speed — against the previous release

v0.3.0 was not measured at its tag. The nearest measurement before it is 2026-10-08, two days
earlier; two of the five figures measured something else then, and the table says so rather than
comparing them.

| Measure | v0.3.0 (nearest: 2026-10-08) | v0.4.0 (2026-10-16) |
|---|---|---|
| run list — cold, app only | not measured then | 378 ms (438 / 374 / 378) |
| run list — warm | 252 ms | 304 ms (308 / 293 / 304) |
| run chosen → panels usable | 240 ms, the first header drawn — another measure | 341 ms (341 / 337 / 378), the report drawn on the first pick |
| narrowing across panels | 167 ms | 117 ms (117 / 122 / 116) |
| trade history drawn | 16 ms | 33 ms (29 / 39 / 33) |

FiniexTestingIDE's container stood at 266 % CPU when the measurement began and at 3 % when it
ended; the figures sit inside the noise of the quiet measurements of the day before.

**The trade history doubled, by the measure's own rule.** The step lies between 2026-10-08 (16 ms)
and 2026-10-12 (32 ms), before most of this cycle, and has held at 28–45 ms through every
measurement since. The fixture did not grow — 18 trades in 4 units throughout. What grew is what a
row carries: its card, the chart mark, the trade groups' headings; and the spec opens the section
from its own header since the panels are docked. In absolute terms the list now takes two frames
where it took one.

**Warm +21 %** is the run list drawing the rows of closed families too, so that opening one moves no
column (+74 ms when it was built, measured alternately with and without), on an index that grew
from 85 to 154 runs.
